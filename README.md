# 100-Days-of-Python---Custom-Learning-Plan
A custom-developed learning plan of 100 Python projects designed to take one from the lower end of intermediate to the lower end of advanced, with a solid grasp of the language and confidence building functional tools from it.
While AI was used in the development of the total list of what each day-to-day artifact will be, and the requirements for what a successful artifact looks like; AI was not used at any point to write or assist with writing these programs. Resources used to fill knowledge gaps and debug tough issues: stackoverflow, python 3.14.4 documentation, and individual module/library documentations. You can see the total list of all the projects in this repo. 

Day 1: Wrote Log Parser that returns total number of logs by type

Day 2: Edited Log Parser to include searching by severity, date, and keyword

Day 3: Wrote a program that takes a directory path supplied by the user and iterates through it using a recursive function to search for all files, and return the total file size in KB being utilized by each type of file. Learned the Pathlib module for this.

Day 4: In Process, files lost in transit and need resend before it can be completed....

Day 5: Wrote a program that takes a text file given by the user and parses through it to determine statistics about the file such as word count, sentence count, unique words used, breadth of vocabulary, and the most used words. Useful for text analysis and authorship attribution. Through this, I learned a bit more about comprehensions, file manipulation, and data processing. A challenge that I faced initially was getting the function that returns the average word length to actually read the unique_words dictionary. At first, it was reading letters. That one took about 20 minutes to solve but the solution was fairly simple. I learned about Lambda functions and what they do in order to complete this micro-project. Lastly, I refined my architecture development skills by taking the project requirements given by ChatGPT and breaking them out into what data I'll need to track, what data type it should be, how I should track it optimally, and what needs to be done to it. I created a flowchart and full pseudocode for this project, developed an initial working artifact, and then refined twice before shipping. As with all projects in this REPO, this was done without the use of AI. Skills refined: Reading files with context managers, File-path validation with pathlib, String manipulation and character filtering, List and generator expressions, Dictionaries and frequency counting, Dictionary .items(), Tuple indexing, Sorting dictionary data by value, Lambda functions as sorting keys, Basic statistical calculations, Input validation, Functions, Python's __name__ == "__main__" entry-point pattern
